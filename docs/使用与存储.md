# 使用与存储

## 开始积累

加载扩展后，在 TUI 持久会话中正常工作。第一次发送消息时，扩展会创建记忆目录及 `topics/`，但不会预先生成空索引或主题文件。

遇到值得记住的内容，当前 Agent 可以使用 Pi 自带的文件工具保存。重要事项也可以直接要求：“把这个约定记下来，注明只适用于项目 A。”工具成功返回后，再检查它说明的保存位置。

后续消息会载入最新索引。需要历史背景时，Agent 按索引读取相关主题；找不到入口时使用普通搜索工具查找目录。没有必要每轮读取全部文件。

## 文件示例

`MEMORY.md` 每个主题一行，只保留链接和检索提示：

```markdown
- [项目 A 测试约定](topics/项目A-测试约定.md) — 集成测试前置条件
- [用户偏好](topics/用户偏好.md) — 稳定的沟通和协作约定
```

主题正文可按内容自由组织，例如：

```markdown
# 项目 A 测试约定

适用范围：项目 A 的本地集成测试。
记录日期：YYYY-MM-DD。

运行集成测试前需要启动本地 Redis。
依据：用户明确说明；尚未重新验证当前测试配置。
```

现有主题应先读后改。添加新主题时先保存正文，再更新索引；纠正或忘记某个结论时同步调整相关内容和入口。扩展只自动读取根目录的 `MEMORY.md`，其他目录与文件不会自动导入或迁移。

## 命令

| 命令 | 作用 |
| --- | --- |
| `/memory` / `/memory status` | 查看当前开关状态和目录 |
| `/memory on` | 为后续消息启用记忆提示 |
| `/memory off` | 为后续消息关闭记忆提示 |

命令开关只影响当前扩展实例，不写入全局配置。`off` 不删除记忆、撤销文件权限或清除对话中已经出现的内容。

## 环境设置

| 设置 | 默认与含义 |
| --- | --- |
| `PI_MEMORY_DIR` | 默认 `~/.agents/memory/`；可改为自己的绝对目录 |
| `PI_MEMORY=0` | 启动时关闭记忆提示 |
| `--no-memory` | 本次启动关闭记忆提示 |

在符合条件的会话中，可用 `/memory on` 显式重新开启。扩展不会在 RPC、print、json 或没有持久会话文件的运行中启用记忆。

## 长索引和人工维护

索引载入上限为 200 行、25000 UTF-8 字节，以先到者为准。超出时，模型会看到开头部分与精简提示；完整文件仍在磁盘。把详细知识移入主题文件、合并重复导航即可，不需要删除仍然有效的知识。

可以直接用编辑器修改 Markdown。文件更新会在下一轮读取；无需重新启动 Pi。删除主题时也应删除对应索引链接。

不保存凭据或敏感原文。模型可能误记范围、状态或结论，重要事项应回到当前源码与证据核实。跨项目共用默认目录时，文件名和正文应明确项目范围。

没有自动清理、历史归档或快照恢复。若需要备份，可按自己的普通文件备份习惯管理该目录。
